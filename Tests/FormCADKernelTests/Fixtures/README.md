# Exact STEP assembly fixtures

These small engineering fixtures are generated by LAB's own `scripts/cad-step-fixture.cpp` using the pinned OCCT 8.0.1 kernel. They contain a nested assembly, two repeated instances of a named box, a named cylinder, nonzero local/world placements, source surface colors and a distinct blue face color. No supplier or user geometry is included.

`colored-assembly.step` is self-contained. `external-reference.step` adds a STEP reference to `../never-read-this.step` using STEPConstruct_ExternRefs; the importer must reject it before XCAF's Transfer can open an external file.

Compile the generator against `.local/engines/occt-8.0.1/include/opencascade` and its shared libraries (TKDESTEP, TKXCAF, TKCAF, TKLCAF, TKCDF, TKXSBase, TKPrim, TKTopAlgo, TKBRep, TKMath, TKernel), then pass the two output paths. The test locates source fixtures relative to #filePath and does not modify them.
