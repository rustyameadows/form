# Inspector controls

Canvas, Table, paper, fabric, CAD, print settings, and appearance controls share the components in `Sources/FormApp/InspectorControls.swift`. Single and split layouts mount the same inspectors.

- `InspectorStyle` defines fonts, 28-point controls, corner radii, row spacing, 16-point panel padding, and section spacing. Use `InspectorRow`, `InspectorSectionHeader`, `InspectorDivider`, and `inspectorSurface()` for consistent layout. Keep panel separators inside the horizontal padding. Native menu separators remain native `Divider`s.
- `ArtworkUnitField` accepts physical dimensions, including explicit units, and stores millimeters. `ScalarArtworkField` handles other numeric values. Both preserve drafts, validation, focus, keyboard stepping, text composition, and commit notifications. `InspectorValueBox` supplies their shared chrome; `InspectorTextFieldStyle` supplies the matching text-field chrome.
- `InspectorSlider` is an actual `NSSlider`, with a custom track and thumb. Its value and accessibility range are the real model range. It supports continuous dragging, keyboard repeat, Shift stepping, and accessibility increments. Pair mutations with `store.inspectorInteraction(key)` or `session.inspectorEditing` to group a gesture into one Undo. Those closures retain their own interaction generation so a late callback cannot finish another edit.
- `inspectorPicker()`, `inspectorSegmented()`, `inspectorToggle()`, `InspectorSymbolChoice`, and `InspectorSymbolToggle` provide matching labels and control treatment while retaining native menu and switch behavior.
- `InspectorColorPicker` opens a shared, movable material-backed radial color panel. Pin it to keep it open. Its explicit Apple picker button opens Apple’s shared `NSColorPanel` through an exclusive app-owned color well. Opening either picker never changes the model. Activating another native color well releases the Apple picker lease; closing our panel leaves the other well active. Pass a target ID that includes the project, object or selection, channel, and any text range or sub-selection. Pass an editing callback for live document mutations. The picker retains the exact callback for a gesture and rejects events from an obsolete target. RGB values retain floating-point precision; alpha behavior follows `supportsOpacity`.
- `LinkedObjectInspectorModule` is the shared collapsible top module. Canvas resolves the associated physical object; Table resolves its flat source, including paper, sewn patterns, and named CAD surfaces. Previews retain canonical project context, use bounded rendering and caching, and navigate existing IDs without creating artwork, adding history, or changing the layout. Source linking, fit, and detach remain in `ArtworkSourcePanel`.

Type controls use the same numeric fields, font and style menus, alignment and decoration buttons, sliders, color control, and inset section spacing. Advanced paragraph and font-feature controls remain available in disclosure groups.

## Validation

The native regression pass covered 126 checks for typography, fonts, colors, physical page setup, paper, fabric, cameras, parameter editing, and retained single/split hosts. After correcting the new control failures, all 28 affected controls/navigation/retention checks passed; the final color-panel pass passed all nine lifecycle, precision, appearance, and placement checks.

Native production-view proofs also exercised Canvas, paper, and generic-object color edits with a run-loop yield during each drag: opening made no document/history changes, each drag created one Undo, and Undo restored the source exactly. Side-by-side and stacked previews contained real artwork and retained canonical source, selection, layout, and history through thumbnail navigation. At 286/330-point inspector widths, all 37 fully visible native field/slider centers passed hit testing, with no horizontally clipped controls. A partially visible row at the bottom of a scroll view was excluded from those hit counts.

## Independent viewports and shared chrome

Canvas keeps its own source, frame, element selection, and linked physical context. Table keeps `engine.selection`, its panel selection, and camera. Passive selection and reconciliation never navigate the peer viewport. Source edits still update their linked rendered objects. Linked previews and the Canvas context menu expose explicit Find actions; Find on Table selects and centers the target without opening a closed inspector or changing the Canvas selection.

Table inspector visibility is separate from selection. A native Table pick opens its inspector; its close button hides only the panel. The toolbar can reopen it while retaining the selection. Visibility survives switching single, side-by-side and stacked layouts. Both inspectors use `FloatingPanel` and `FloatingPanelHeader` with the same width, inset separator, height, padding, border and shadow. `AppCloseButton` is the single custom close control used across inspectors, popovers and utility headers. Native macOS window controls remain system-owned; deletion actions use removal symbols.

Canvas and Table docks use `WorkspaceToolbarButton`, `WorkspaceToolbarMenuLabel`, `WorkspaceToolbarDivider`, and `WorkspaceToolbarSurface`: SF14 symbols, 32-point icon targets, one selected/hover treatment, and identical spacing and outer chrome. Orbit, Move and camera presets are icon-only with descriptive tooltips/accessibility labels. Both docks retain every action through horizontal overflow rather than swapping in a compact variant.

The independence/chrome pass exercised 113 native regressions. After correcting native alignment, accessibility activation and measurement issues, all 22 affected panel, toolbar, navigation, visibility and color checks passed. Toolbar tests measure the real 32-point native bounds and all four hit corners; accessibility frames may additionally include AppKit’s focus-ring outset. Close targets remain exactly 28 points. Both control sets use actual native actions rather than test-only callbacks.
